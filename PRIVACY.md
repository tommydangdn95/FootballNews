# Privacy Policy – Matchday Live Bot

_Last updated: 2026-11-07_

Matchday Live Bot is a private tool operated by the administrator of the Facebook Page **Matchday Challenge Việt Nam**. It publishes football match updates (scores, goals, red cards, half-time and full-time results) to that Page after the administrator approves each post.

## Data we collect
The app does **not** collect, store or share personal data of Facebook users.

- It only uses a Page access token to publish posts to the Page **Matchday Challenge Việt Nam**.
- It does not read profiles, friends, messages, comments or any other information of Facebook users.
- Match data comes from public football data sources (ESPN).

## Data storage
The app stores only technical state needed to avoid duplicate posts (match IDs, scores already posted). This state contains no personal data.

## Data deletion
Because the app stores no personal data of Facebook users, there is nothing to delete. If you still want to request deletion or have questions, open an issue at
https://github.com/tommydangdn95/FootballNews/issues
and it will be handled within 30 days.

## Changes
Changes to this policy will be published on this page.

# Chính sách quyền riêng tư – Matchday Live Bot

Matchday Live Bot là công cụ riêng của quản trị viên Fanpage **Matchday Challenge Việt Nam**. Bot đăng thông tin trận đấu (tỉ số, bàn thắng, thẻ đỏ, kết thúc hiệp 1, kết thúc trận) lên Fanpage sau khi quản trị viên duyệt từng bài.

- Bot **không** thu thập, lưu trữ hay chia sẻ dữ liệu cá nhân của người dùng Facebook.
- Bot chỉ dùng Page access token để đăng bài lên Fanpage **Matchday Challenge Việt Nam**.
- Dữ liệu trận đấu lấy từ nguồn công khai (ESPN).
- Bot chỉ lưu dữ liệu kỹ thuật để tránh đăng trùng (mã trận, tỉ số đã đăng), không có dữ liệu cá nhân.
- Yêu cầu xoá dữ liệu hoặc câu hỏi: tạo issue tại https://github.com/tommydangdn95/FootballNews/issues
